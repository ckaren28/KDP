## The campaigns

Each campaign was pinned to a film or series release date that wasn't going to move. The same
spreads ran in *Variety*, *Cinefex* and *Blickpunkt*, alongside iPad ads that linked straight to
the site, so the site had to be ready the day they ran.

## An editorial, video-first site

The direction, agreed in regular meetings with the CEO, was an editorial magazine, and heavy on
video, as you would expect from a visual effects studio. Most footage arrived as high-definition
.mov files far too heavy for the web, so I learned a lot about compression, lossless versus
lossy, and getting pages to load fast without the reels looking worse. I built it on a LEMP
stack with a WordPress theme written from scratch, so campaign layouts could change every month.

## Print doesn't let you iterate

Print was the only work I've done that couldn't change after it shipped. You make the decisions
before it exists, which is a different discipline from the one screens teach.
